# Architecture Decision Records (ADR)

Decisões arquiteturais irreversíveis ou controversas vivem aqui — **não** duplicam `docs/ECOSSISTEMA.md`.

## Formato

- Arquivo: `NNNN-titulo-em-kebab-case.md` (ex.: `0001-narration-only-motor.md`)
- Template e processo: `.cursor/rules/dndai-documentation-architect.mdc`
